Install guide

Everything you need to download and run our Windows apps. Takes about five minutes.

Before you start

  • Windows 10 or Windows 11, 64-bit. Check under Settings > System > About.
  • Enough free disk space for the app. Each app page lists its size.
  • An administrator account, if your PC is managed by your organisation. Ask your IT team if you are unsure.

Step 1: Download

Open the app page from the Apps list and press Download for Windows. Your browser saves the installer to your Downloads folder. Installers are named with the app and version, for example ResumeForgeAI-Setup-1.0.0.exe.

Step 2: Run the installer

  1. Open your Downloads folder and double-click the installer.
  2. If Windows asks "Do you want to allow this app to make changes to your device?", choose Yes.
  3. Follow the on-screen steps. Keep the default options unless you have a reason to change them.
  4. Wait for the progress bar to finish, then press Finish.

SmartScreen warnings

Windows Defender SmartScreen checks files that are new or not yet widely downloaded. You may see this message:

"Windows protected your PC. Microsoft Defender SmartScreen prevented an unrecognized app from starting."

This does not mean the file is infected. It means Windows has not seen many people download it yet. To continue:

  1. Click More info.
  2. Check that the file name matches the app you downloaded from this site.
  3. Click Run anyway.

Only do this for files downloaded directly from this site. If the file name or source looks different, do not run it. Contact us instead.

Step 3: Open the app

Find the app in the Start menu, or use the desktop shortcut if you chose one during setup.

Updating

Download the latest installer from the app page and run it. It replaces the older version. Check the changelog to see what changed.

Uninstalling

Go to Settings > Apps > Installed apps, find the app, select the three-dot menu, and choose Uninstall.

Troubleshooting

The download was blocked or deleted

Some browsers and antivirus tools block unfamiliar installers. Check your browser's download history or the antivirus quarantine. Allow the file only if it came from this site.

The installer will not start

Right-click the file and choose Run as administrator. If it still fails, confirm your Windows version meets the requirements on the app page.

Still stuck?

Read the FAQ or send us a message with your Windows version and the exact error text.
