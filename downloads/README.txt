Installer files go in this folder.

Current expected file:
  ResumeForgeAI-Setup.exe   -> served at /downloads/ResumeForgeAI-Setup.exe

The download button on each app page points here. The file name must match
the "file" field in apps.json (apps.json uses /downloads/ResumeForgeAI-Setup.exe).

Vercel size limits: confirm your installer fits. If a file is too large for
Vercel static hosting, host it on GitHub Releases or object storage and change
the "file" URL in apps.json to that address.

This README is not a deployable file and can be deleted before deploying.
