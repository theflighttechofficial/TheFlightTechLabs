    Getting started

    1. Download the installer using the button on this page.
    2. Run it. It installs for your user only and does not need administrator rights.
    3. Launch FocusBuddy from the Start menu. The setup wizard helps you pick a companion and decide what to do about distractions.
    4. Optional: install the FocusBuddy Connector browser extension so the app knows the exact website. The wizard turns green when it connects.
    5. Right-click your companion and choose Start Focus Session.

    The installer is not code-signed yet. If you see "Windows protected your PC", click More info, then Run anyway. See the SmartScreen guide.
