Install in three steps

From download to running

Download

Press the download button on any app page. The installer saves to your Downloads folder.

Run the installer

Open the file and follow the on-screen steps. Approve the Windows permission prompt if it appears.

Launch

Find the app in the Start menu or on your desktop, then open it.

Seeing "Windows protected your PC"? This is normal for new installers. Click More info, then Run anyway. Read the full explanation.
